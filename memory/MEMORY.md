## 核心鐵律清單
- 🔴 **Outlook 紅旗/待處理郵件保護鐵律**：查詢或整理 Outlook 郵件時，凡帶有「紅色旗標 (Flagged)」或標示為「待處理」的郵件，絕對禁止自動搬移或刪除。
- 🔴 **未寫 NG 絕不臆測原則**：解析品保檢驗結果或報告時，若無明確載明「NG」，純屬特徵/現象觀察紀錄，嚴禁自行推論或臆測為不合格品。
- 🔴 **Zero-OOM Excel 解析鐵律**：讀取企業現場 `.xlsx` 台帳一律先執行 4-Byte (`PK\x03\x04`) 檔頭檢查並採用 Last-Value 截斷法，禁止直接載入百萬空白列。
- 🔴 **Ollama 模型存放規範**：本機所有 LLM 模型必須存放在 `D:\OllamaModels`（環境變數 `OLLAMA_MODELS`），嚴禁大量寫入 C 槽。
- 🔴 **嚴禁洩漏機敏資訊**：`.env`、API Key、MES/SEVI 帳號密碼絕不回傳至未授權介面或寫入版本控制紀錄。
